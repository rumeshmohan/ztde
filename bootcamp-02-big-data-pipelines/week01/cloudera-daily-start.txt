CLOUDERA QUICKSTART - DAILY START / STOP
Run all commands in PowerShell (not Git Bash).
=========================================================


START
-----
1. Open Docker Desktop. Wait until it says "Engine running".

2. Start Cloudera:
   docker start cloudera

3. Watch services start. When "Starting hue ... OK" appears, press Ctrl+C:
   docker logs -f --since 5m cloudera

4. Open a Cloudera shell (run lab commands here):
   docker exec -it cloudera su - cloudera


WEB PAGES (login cloudera / cloudera)
-------------------------------------
Hue ..................... http://localhost:8888
HDFS NameNode ........... http://localhost:9870    (NOT 50070, Windows blocks it)
YARN ResourceManager .... http://localhost:8088


QUICK HEALTH CHECK (inside the Cloudera shell)
----------------------------------------------
hadoop version | head -1
hdfs dfs -ls /


STOP (when you finish)
----------------------
Type  exit  to leave the Cloudera shell, then:
   docker stop cloudera


IF SOMETHING GOES WRONG
-----------------------
"failed to connect to the docker API"
   -> Docker Desktop is not running. Open it and wait.

HDFS writes fail / "safe mode"
   -> Wait 1 minute after start. If it stays, inside the Cloudera shell:
      sudo -u hdfs hdfs dfsadmin -safemode leave

"Failed to start Hadoop historyserver" in the logs (stale PID after a stop)
   -> In PowerShell:
      docker exec cloudera bash -c "rm -f /var/run/hadoop-mapreduce/*.pid; service hadoop-mapreduce-historyserver restart"

Hue does not open
   -> Services still starting. Wait 5 minutes and refresh.

Start from scratch (deletes everything inside the container):
   docker rm -f cloudera
   docker run -d --name cloudera --hostname=quickstart.cloudera --privileged=true -t -i --ulimit nofile=65536:65536 -p 8888:8888 -p 7180:7180 -p 80:80 -p 9870:50070 -p 8088:8088 ghcr.io/zuucrew/cloudera-quickstart:cdh5.7 /usr/bin/docker-quickstart
